## 1. 三种变体（原型对比）

| | A — 表格矩阵优先 | B — 卡片墙 + 抽屉 | C — 工具泳道 + 时间线 |
| --- | --- | --- | --- |
| 一级导航 | 左侧栏 | 顶部 tab | 工具为一级（库/四工具/快照/设置） |
| 核心视图 | 大矩阵表（技能 × 工具） | 技能卡片网格 + 右侧抽屉 | 仪表盘统计卡 + 工具部署列表 + 常驻快照时间线 |
| 差异查看 | 行内展开 | 抽屉内 tab | 行点击纵向 inline diff |
| 分发交互 | 行首勾选 + 底部批量条 | 卡片内操作 + 底部批量条 | 行级操作为主 |

## 2. 确认记录（2026-08-09 与用户确认）

| # | 决策点 | 结论 |
| --- | --- | --- |
| 1 | 整体信息架构 | **变体 A（表格矩阵优先）**：左侧栏导航 + 技能 × 工具矩阵表为主视图 |
| 2 | 展开的差异对比 | **占满整行**，不再双栏；**不展示分发目标面板**（分发目标编辑移出展开区） |
| 3 | 列级快捷分发 | 每个工具列头部增加**「分发全部」按钮** = 一键分发全部技能行到该目标工具（替代顶栏一键全发） |
| 4 | 行级 diff 查看 | **行内展开**：不打断列表上下文，diff 较长时高度受限、行内省略可悬停展开 |
| 5 | 快照时间线（回滚入口） | **弱化**：主界面不常驻，独立「快照时间线」页查看；工具/行上下文提供回滚按钮 |
| 6 | 批量分发 | **行首勾选 + 底部批量条**：勾选后出现「已选 N 项 / 取消 / 分发所选」（分发所选 = 分发到各自 targets 标记的工具） |
| 7 | 视图划分 | 库视图（状态矩阵）、导入向导、快照时间线、设置（工具启用与路径）四页；WorkBuddy 未配置显示「未接入」与配置引导 |

## 3. 关联与留后续

- **行级 diff 数据来源**：状态由 #6 引擎三方 hash 判定，diff 内容为「Vault 当前 vs 工具端当前」文件内容比对；hash 不一致但 diff 为空（目录结构变化）时展开区提示
- **分发前重扫提示**：扫描有变化时顶栏/批量条区域出现提示条（文案待定，属 #8 或实现阶段）
- **勾选持久化**：MVP 勾选为会话态，刷新即清（不落 SQLite）
- **i18n 预留**：原型文案带 `data-i18n` 语义 key；实现阶段抽 `zh-CN` 语言包
